* State locking

* Terraform drift
* Module design
* `for_each` / dynamic resources
* Backend configuration
* Plan / Apply failures

* VNet & subnet configuration
* NSG rules
* Load Balancer configuration
* VM connectivity
* Private/Public IP issues
